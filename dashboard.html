Welke bestanden werken? Een GA4 CSV met kolommen zoals Page path and screen class / Views of Paginapad / Weergaven. Voor Search Console een export met Top pages / Clicks / Impressions of Pagina's / Klikken / Vertoningen. Een datumkolom is optioneel, maar nodig om op perioden te filteren. Exports zonder datum worden alleen bij ‘Alle data’ getoond. Het dashboard bewaart geen gegevens na het sluiten of verversen van de pagina.
